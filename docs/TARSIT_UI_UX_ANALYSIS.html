🚀 App Overview

Tarsit is a modern local business discovery platform that connects users with businesses in their area. It features an AI assistant named "TARS" for enhanced user experience.

User Roles

👤 Guest User
Can browse businesses, search, view details, and access public pages. Prompted to sign up for full features.
👥 Registered Customer
Can book appointments, save favorites, message businesses, leave reviews, and manage their profile.
🏪 Business Owner
Full business management: profile, services, appointments, team, analytics, photos, hours, and settings.
🛡️ Admin
Platform administration: user management, business verification, content moderation, system health.

🤖 TARS AI Assistant

components/tars/

TARS is the AI assistant that helps users navigate the platform, find businesses, and get support.

Components

Component Purpose
TarsWidget Floating chat button and panel
TarsChat Chat interface with messages
TarsAvatar Animated AI persona avatar
TarsTooltip Contextual help tooltips
TarsOnboarding First-time user walkthrough

Persona System

👋 Guest Persona
Discovery focused. Helps explore businesses, encourages signup. Friendly, informative tone.
👤 Customer Persona
Personal concierge. Assists with bookings, favorites, reviews. Helpful, personalized tone.
🏪 Business Persona
Business advisor. Helps with dashboard, analytics, optimization. Professional, supportive tone.

Context Modes

  • general - Default help mode
  • search - Business discovery assistance
  • booking - Appointment booking help
  • business - Business profile context
  • analytics - Dashboard analytics help
  • messages - Messaging assistance
  • schedule - Calendar/hours help

Features

  • Keyboard shortcut: Cmd/Ctrl + K
  • Quick action buttons with icons
  • Markdown link parsing
  • Session persistence
  • Context-aware responses
  • Real-time streaming
